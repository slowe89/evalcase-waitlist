What’s in a pack

  1. Immutable case revisions + run provenance

    Every pack ships with versioned case IDs and enough run metadata to reproduce a grade — not a one-off YAML dump.

  2. Typed-output and judge-score normalization

    We treat numeric strings, schema drift, and sibling-metric mismatch as pack defects to catch before a real eval fails on typing.

  3. Refresh when tools move

    Optional retainer keeps packs current when MCP servers, tool schemas, and harness conventions churn — provenance stays intact across refreshes.

Who it’s for

Evaluation and applied-research leads; builders of tool-using agents; vendors that need customer-facing harnesses.

Who it’s not for

Not an llms.txt / MCP marketing site, a $99/mo eval SaaS seat, or a judge-model fine-tune shop.
